# Thu muc bin/ — dat ffmpeg vao day de bundle kem app

Whisper can ffmpeg de doc mp3/mp4. Truoc khi build, tai ban **static** cho dung he dieu hanh va dat vao day:

| He dieu hanh | File can co | Tai o dau |
|---|---|---|
| Windows | `bin/ffmpeg.exe` | https://www.gyan.dev/ffmpeg/builds/ (ffmpeg-release-essentials.zip) |
| Linux | `bin/ffmpeg` | https://johnvansickle.com/ffmpeg/ (static build) |
| macOS | `bin/ffmpeg` | https://evermeet.cx/ffmpeg/ |

Neu khong bundle (Linux), script build se tu khai bao dependency `ffmpeg` cua he thong.
